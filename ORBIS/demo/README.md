# 合并演示版（免费版 / 完整版）

`orbis_demo.html` 是「ORBIS 地球 ＋ 登录门 ＋ 方案分层 ＋ 国家档案卡 ＋ 对比盒子 ＋ 俯冲转场 ＋ 飞升」拼起来的单文件演示版，用来展示同一份数据在免费版与完整版下的差别。

在线地址：<http://8.137.183.172:8080/demo>（服务器上对应 `/opt/orbis/demo.html`）。双击 `orbis_demo.html` 也能直接打开。

## 打开方式

| 入口 | 说明 |
|---|---|
| `/demo` | 先进登录门，选「基础版 / 完整版」 |
| `/demo?plan=free` | 跳过登录门，直接进基础版 |
| `/demo?plan=pro` | 跳过登录门，直接进完整版 |
| `/demo#/c/RUS` | 直接打开俄罗斯的国家页 |

## 三层内容

**基础版**：地球 → 国家，三个核心数字、洞察句、GDP 走势、人口结构、分享名片。
**完整版**：再加全球位次、邻国对照、九项指标表、多国对比、飞升。
**门控方式**：锁定区块保持可点击（灰化 + 「完整版」徽标），点击给出升级提示，而不是藏起来。

## src/ 里的东西

```
mk_demo.py          构建脚本：搭档原版 + 外壳 + 各模块 → orbis_demo.html
plan_shell.html     外壳：登录门 / 方案切换 / 门控规则
mk_carddata.py      从 app_data.json 裁出卡片要用的字段 → card_data.js
card_data.js        26 年 × 10 指标 + 国旗 + 陆地邻国（由上面那个脚本生成）
earth_tex.jpg       飞升用的地球贴图（构建时 base64 内联）
peer_card.js/css    国家档案卡（三个数字 / 洞察 / 走势 / 人口结构 / 位次 / 邻国）
peer_cmp.js/css     对比盒子（拖国家进盒子 → 生成对比图 → 存 1080×1440）
peer_dive.js/css    俯冲转场（点国家时地球以点击点放大，国家页随后淡入）
peer_space.js/css   飞升（独立 WebGL 太阳系场景，八大行星档案卡）
```

```bash
python mk_carddata.py   # 只有改了 app_data.json 才需要重跑
python mk_demo.py       # 重新生成 orbis_demo.html
```

## 两个实现上的取舍

**不碰搭档的渲染内核。** `peer_*.js` 只读三样东西：hash 路由（`#/c/XXX`）、底部指标条（`#dchips button.on`）、顶部年份（`#dyr`）。对方的压缩代码一行没改，所以两边可以各自迭代。

**卡片数据另生成一份精简包。** 主站的 `app_data.json` 有 233KB、字段很全；卡片只用 10 个指标，所以裁成 328KB 的 `card_data.js`（含国旗 base64 与邻国表），内联进页面，保证单文件可离线运行。

## 已知限制

- 窗口宽度 ≤ 700px 时不显示国家档案卡（手机上搭档自己有一块面板，叠加会互相遮挡）
- 省市下钻（第五级）不在这一版里，那套仍在 Atlas 中
- 登录与方案选择是前端演示态，账号存在浏览器本地，未接后端
