# 登录封面改版（ORBIS Gate）

把 `ORBIS/orbis.html` 里原来那层「科技风」登录封面，换成编辑部 / 画册式的版式。

## 改了什么

| | 原来 | 现在 |
|---|---|---|
| 字标 | 12px 等宽小字 `ORBIS` | Georgia 衬线大写字标，`clamp(62px, 7.4vw, 104px)`，字距 .15em |
| 文案 | 橙色 kicker「用数据重新认识这颗星球」＋「欢迎回来，探索者」 | kicker 与欢迎语全部删除，改为一条 54px 发丝线 ＋「带你用数据看世界」 |
| 右侧 | 线框球（经纬网 + 轨道弧 + HUD 标签 + 扫描线） | Three.js r128 真实贴图地球：亚洲居中、柔和侧光、辉光大气、极慢自转 |
| 表单 | 卡片式外框 | 只有下划线的输入框；按钮改为暖白实心 + 2px 圆角 |
| 强调色 | 橙色（赛博朋克套路） | 古铜金（`#c8a06a` 系），只用在 1px 下划线与 hover |

删掉的所有东西（等宽 HUD 文本 `ORBIT / 1.00 R`、`GRATICULE 8–18`、坐标读数、网格底纹、扫描线、年份刻度）都是「科技感」的来源；留下的是版式：一个字标、一条细线、一句副标，其余留白。

登录后的欢迎层也同步了文案：`从太空看地球 · 欢迎回来，探索者` → `从太空看地球 · 带你用数据看世界`。

## 文件

```
gate.html        封面结构（含 {{EARTH_B64}} 占位符）
gate.css         封面样式（#authgate / .ag-* 命名空间）
gate.js          地球渲染（Three.js r128，独立 canvas，不碰主页面渲染器）
patch_gate.py    把上面三件套打进 orbis.html
```

## 怎么重新生成

`patch_gate.py` 以一个「未改过封面的 orbis.html」为输入，做四步替换：

1. 样式：`/* 登录封面 */ … /* 搜索 */` 之间，只丢弃门控相关的规则，`#brand` 等主页面规则原样保留
2. 结构：`<!-- 登录封面：进入主界面之前 -->` 到 `<canvas id="globe">` 之间整段替换
3. 脚本：旧的「登录页动态线框地球」IIFE 整段替换
4. 文案：登录后欢迎层的副标替换

```bash
python patch_gate.py
```

脚本里 `SRC` 默认指向本地开发目录的原始页面，按需改成仓库里的 `ORBIS/orbis.html` 的旧版本（改版前的那一版）即可。地球贴图用 `../build/earth_tex.jpg`，会被 base64 内联进 HTML。
