## 1. 单文件构建（backend 无关，frontend/build_globe.py）

```python
tpl   = read("globe_template.html")
three = read("three.min.js")
data  = read("../data.js")

def uri(name, mime):  # 文件 → data URI
    return "data:%s;base64,%s" % (mime, b64encode(open(name,'rb').read()))

TEX = {
  "__TEX_DAY__":     uri("earth_day_4k.jpg", "image/jpeg"),
  "__TEX_NORMAL__":  uri("earth_normal_2048.jpg", "image/jpeg"),
  "__TEX_SPEC__":    uri("earth_specular_2048.jpg", "image/jpeg"),
  "__TEX_CLOUDS__":  uri("earth_clouds_1024.png", "image/png"),
}
html = tpl.replace("/*__THREE_JS__*/", three).replace("/*__GLOBE_DATA__*/", data)
for k, v in TEX.items(): html = html.replace(k, v)
write("../orbis.html", html)
```

- 6 个占位符：THREE_JS / GLOBE_DATA / TEX_DAY / TEX_CLOUDS / TEX_NORMAL / TEX_SPEC
- 防御检查：three.min.js 若含 `</script>` 会提前闭合脚本，脚本直接报错退出
- 贴图默认 4K；`ORBIS_TEX=8k` 切 8K（页面 5.6MB → 11MB）
- 线上 gzip 压到 2.52MB + ETag/304 缓存

**Q: 为什么不用 Webpack/Vite？**  
A: 交付要求是双击即开的单 HTML，框架反而要额外产物；这个脚本本质就是极简 bundler。

### 按需渲染 + 动态分辨率（性能核心）

```js
var HQ_PR=Math.min(devicePixelRatio||1, isSmall?1.5:2), LQ_PR=1;
var dirty=true, settle=0;
function markDirty(){ dirty=true; }

function animate(now){
  requestAnimationFrame(animate);
  var dt=Math.min((now-lastT)/1000,0.05);

  // motionDrag=拖动/惯性(必须低采样)；autoSpin=自动慢转(保持高清)
  if(state.anim){ /* ease-in-out cubic 插值 */ motionDrag=true; }
  else if(!drag && pointers.size===0){
    if(Math.abs(state.vT)>1e-4){ state.theta+=state.vT; state.vT*=0.93; motionDrag=true; }
    else if(state.autoOn && now-state.last>4200){ state.theta+=dt*0.045; autoSpin=true; }
  }

  var wantPR=(motionDrag||perfMode)?LQ_PR:HQ_PR;
  if(motionDrag) settle=2;              // 松手后补 2 帧高清
  setPR(wantPR);
  if(motionDrag||autoSpin) dirty=true;
  else if(settle>0){ settle--; dirty=true; }
  if(dirty && !CV.open){ renderer.render(scene,camera); dirty=false; }
}
```

三层优化：①脏标记（静止时根本不调 render）②拖动降 pixelRatio=1（像素量 1/4）③流畅模式隐藏云层+始终低采样。

### 双 renderer 坑（重点讲）

主地球与登录页球是两个 WebGLRenderer。**共享 texture 对象会黑球/白球**（GPU 状态/encoding 冲突）。解法：贴图 URL 存全局变量 `AG_DAY_URL` 等，各自独立 `TextureLoader` 加载；页面只内联一份 base64。

```js
IND = {

  gdp: {log:[8, 13.56]},

```

线性映射会把中小国家压成一色（GDP 差 200 倍），必须对数。

### 变化指标用对称对数

```js
// 中位 +197%、最高 +2097%，线性会被极值拉爆
if(v>=0) t = 0.5 + 0.5*log1p(v/scale)/log1p(mx/scale);
else     t = 0.5 - 0.5*log1p(-v/scale)/log1p(mx/scale);
// 零点恒在色带正中，涨跌对称可比；负百分比用 -100% 硬下界
```

## 6. 高频追问速答

| 追问              | 答法                                  |
| --------------- | ----------------------------------- |
| 为什么不用 React/Vue | 单文件离线是硬需求；原生函数+状态对象等价模块化，IIFE 隔离作用域 |
| 数据缺测怎么办         | 平行数组按年份索引，缺测跳过不画，不插值（避免造假）          |
| 怎么保证不卡          | 脏标记按需渲染 + 动态分辨率 + 流畅模式三层            |
| 登录球为什么单独做       | 封面期主场景未初始化完，且共享纹理冲突                 |
| 重做会怎么改          | 引入模块打包（牺牲单文件）、TS 管状态、补前端自动化测试       |
